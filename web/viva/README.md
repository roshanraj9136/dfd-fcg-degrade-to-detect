# Viva guide: architecture, contribution and completed work

The guide starts with the live architecture, then explains every tensor shape,
the two DFD feature concatenations and the final five-score fusion. It includes
English and easy Hinglish recaps, four primary paper links, a viva script, and
downloadable diagrams. Novelty and extra work distinguish inherited methods,
our contributions, shipped changes and experiments that failed release rules.
The original research figures remain in the final research section.

## Architecture diagrams

`src/TensorArchitecture.tsx` provides the diagram selector, enlargement control,
searchable shape explanations, papers and downloads. Regenerate the two SVGs,
two PNGs and two-page PDF with Matplotlib from the repository root:

```sh
python scripts/draw_viva_architecture.py
```

Dimensions were checked against the authors' `src/model/clip/svl.py`,
`qa/engine.py`, `service/app/gend_live.py`, and the stored read-outs. In particular:

- DFD heads concatenate LayerNorm outputs; our correction concatenates raw
  1024 + 256 features before its own fitted standardization.
- GenD normalizes 1024 features with L2 normalization before its head/read-out.
- The deployed PE path resizes inputs to 224 despite the backbone's 336 name.
- Final fusion uses five score logits, not a concatenation of model embeddings.

The guide distinguishes two settings: the initial research protocol uses two
clips and unseen-degradation evaluation; the live checker uses up to eight clips,
two faces and a five-score fusion. Do not present their metrics as interchangeable.
The exact heatmap describes the raw spatial branch, not the full ensemble.
The ensemble's 63.1% baseline is self-calibrated DFD-FCG, not the untouched
detector. Its 705-video aggregate includes cached two-clip DFD scores for the
reported subset; it is not a new end-to-end accuracy measurement of the current
eight-clip production settings. Keep those qualifications next to the headline.

`src/ensemble.json` is generated by `service/ens/report.py`; never edit its numbers.
`src/evidence.json` is a compact export without model tensors or video identifiers:

```sh
# From the repository root:
python scripts/export_viva_evidence.py
python scripts/export_viva_evidence.py --check

cd web/viva
npm ci
npm run build
```

On the restricted Windows environment, esbuild cannot scan a parent directory
while bundling Vite's config. `npm run build -- --configLoader runner` uses Vite's
supported alternate config loader and runs the same TypeScript and production
build checks. CI uses the default build on Ubuntu.

The local audit covered generated-data consistency, production compilation,
server rendering, section links and repository evidence links. Browser visual and
interaction checks require approved browser access; a build is not a visual test.
